# BACTERIA WAR — 게임 변수 정리 (v0.3)

> 2026-06-02 사용자 디자인 정비 기준. 변수 sweep 시뮬 결과는 본 문서 7장.
> *변수 = 시뮬 대상*, *기본값 = 현재 채택 값 또는 시뮬 권장 값*.

---

## 1. 게임 개요

**매크로** (지도): 영구 세계. 플레이어가 1km 반경 안에 *원하는 크기*로 타워를 깔고, 각 타워가 자기 위에 *에너지를 누적 저장*. 플레이어는 주기적으로 타워를 방문해 *수확*. 수확한 에너지로 새 타워 짓거나 적 타워에 도전.

**마이크로** (실시간 전투): 도전 발생 시 그 영역을 아레나로 1:1 (또는 vs AI). 바둑·오델로식 — 균일 돌, 자동 공격, 변환, 동심원 3링.

## 2. 매크로 규칙 (개정)

### 2.1 가입·캐릭터
- 시작 에너지 **100**
- 종족 자동 배정 (최소 종족 우선 — 균형)
- 영구 (자연사 없음)
- *영웅 환생* 시스템 그대로: 사망(영토 전멸) 시 누적 글로리 비례 확률

### 2.2 타워 점유
- 빈 곳 탭 → 크기 **1~100** 슬라이더 → 비용 = 크기 (예: 크기 50 → 100 에너지에서 50 차감)
- GPS 1km 반경 안만 가능
- 자기 셀끼리 겹쳐도 OK (클러스터 형성)
- 적 셀과 너무 가까우면 자동으로 도전 흐름 전환

### 2.3 타워 생산·저장
- 각 타워는 **자기 위에** 에너지 저장 (글로벌 풀 아님)
- 생산률 = `PROD_COEF × size` per second
- 저장 상한 = `CAP_FACTOR × size` (현재 후보: 3.0)
- 저장 가득 차면 생산 정지 → 수확해야 재개

### 2.4 수확
- 내 타워 탭 → 누적 에너지 양 표시 → "수확" 버튼
- 수확량 사용자 선택 (전체 또는 일부)
- 수확한 만큼 플레이어 *글로벌 에너지*에 이전
- 타워 누적은 그만큼 감소 → 다시 생산 가능

### 2.5 매크로 도전
- 적 셀 탭 → 베팅 슬라이더 (들고 갈 에너지) → 도전
- **GPS 반경 제한**: 점유와 같은 1km (`CHALLENGE_RADIUS_M`) — 물리적 존재가 정체성
- 베팅 = 마이크로 전투 시작 에너지
- 이기면 점유권 + 방어 베팅 + **그 타워의 미수확 저장 에너지 약탈** (방치 = 위험)
- 도전 큐 (랜덤 선택, 친구 담합 방지)
- 도전·휴식 (60초 단발 / 5연속 시 1시간 / 일일 10회 시 8시간)
- 베팅 상한 자산 = 에너지 + 보유 셀 가치 합

### 2.6 방어
- 방어 베팅 미리 설정 (자동 방어용)
- 도전 알림 시 직접 응전 OR 자동 방어 (AI)
- 직접 응전 시: 모달에서 방어 베팅 *재설정* (올리기만 — 도전자의 기대 보상 보호)
- **방어 성공 시 도전자 베팅을 방어자가 획득** (증발 아님 — 지킬 맛)
- **수면 보호**: 오프라인 전환(30분 무활동) 후 8시간 동안 도전 불가. 접속하면 해제.

### 2.8 재미 레이어 (v0.4 "욕망의 지도")
- **지도 = 사냥터**: 미수확 에너지 ≥ 10인 적 셀에 금색 펄스 + ⚡양 표시 (`LOOT_SHOW_MIN`)
- 내 타워엔 저장 게이지 링 (가득 = 빨강 펄스 "수확해!")
- **봇 셀엔 약탈 에너지 시드** (15~60, `BOT_LOOT_*`) — 첫 5분에 약탈 루프 체험
- **🏆 순위표**: 영토 가치 상위 10 (봇 제외)
- **실시간 활동 피드**: 점령/격퇴/사망/영웅 환생을 전체 브로드캐스트 (티커)
- **🧺 한번에 수확**: HUD 칩에 수확 가능 총량 표시, 탭 한 번에 전체 수확
- 전투 HUD: **남은 시간 + 돌 수 + 우세 색상** (승리 조건 가시화)
- 결과 화면: 획득 내역 상세 (점유 + 베팅 + 약탈)

### 2.8b 전선 마모전 (v0.6 — 매크로가 살아있다)
- **인접(물리 반경 접촉 + 50m) 적 타워끼리 틱마다 상호 소모** — 세계가 스스로 긴장을 만든다
- 순서: 군량(`stored_energy`) 먼저 소진 → `value` 잠식 (하한 = 최초 가치 × 0.5 — 자동으론 절대 죽지 않음)
- 압박량 = 상대 value × `DRAIN_COEF`(0.0001/틱), 상성 우세 +30% (`COUNTER_EROSION` 실현)
- 시뮬 검증: 1:1 만재 대치 = 군량 42h (안정) / 2:1 포위 = 21h (수적 우위 보상) / 군량 방치 = 14h 반토막
- **교전 중 타워는 생산 정지** — 전선 유지비 자연 발생
- **보급**(🎒): 수확의 역방향, 지갑→타워 군량. 전선 유지가 접속 동기
- 함락은 여전히 마이크로 도전으로만 (매크로는 압박, 마이크로가 결판)
- 예외: 봇은 압박 안 함(받기만), 수면 보호 중 소유자 셀은 전선 제외
- UI: 지도에 붉은 톱니 링+불꽃, 셀 시트 "⚔ 교전 중 −X/h"
- **타워 벡터 그래픽**: 어셋 파일 없이 캔버스 프로시저럴 — 가치별 3단계(포탑/타워/요새) + 봇 로봇 헤드, 종족색 틴트

### 2.9 v0.5 추가 레이어
- **전투 사운드**: WebAudio 합성 (에셋 파일 없음) — 배치/발사/타격/변환/사망/카운트다운/승패. 🔊 음소거 토글 (localStorage)
- **데일리 퀘스트** (KST 자정 리셋): 전투 3승(⚡60) / 약탈 2회(⚡50) / 수확 100(⚡40). 📜 버튼 + 완료 배지, 서버 권위 진행·수령
- **클러스터 시너지 시각화**: 지도에 내 셀 간 800m 보급선(흐르는 점선), 도전 시트에 "시작 돌 나 N vs 상대 M" 예측, 점유 시트에 보급망 연결 수
- **PvP 서버 권위**: 수락 즉시 서버 아레나 생성 (20Hz 시뮬·10Hz 스냅샷, `pvpArena.js`). 클라는 입력(`pvp:input`)만 전송, 서버가 검증·판정·정산(`pvp:end`) — 결과 위조 원천 차단. 돌이 정적이라 예측/보간 불필요. vs AI 전투는 기존 클라 시뮬 + sanity check 유지

### 2.7 종족 상성 (가위바위보)
- 마이크로 전투에서 상성 우세 진영 **생산 +15%** (`TRIBE_ADV_INCOME_BONUS`)
- 전투 시작 바에 우세/열세 표시

## 3. 마이크로 규칙 (바둑·오델로식)

### 3.1 아레나
- 원형, 반경 = `min(W,H) × ARENA_RATIO` (0.42)
- 시간 상한 = `MAX_T` (현재 120초)
- 카운트다운 3초 후 시작

### 3.2 돌
- **균일 크기** (반경 18px, HP 30, 비용 = 위치 ring별)
- 시작 돌: 좌·우 끝에 1개씩 + 보급선 보너스(매크로 셀당 +1, 최대 +4)
- 영웅 시작: 해당 진영 생산 +50%

### 3.3 동심원 3링 (위치별 비용·생산 차등)
- `RING_INNER_R` (= 0.18): 안쪽
- `RING_MIDDLE_R` (= 0.40): 중간
- 그 외: 외부

| 링 | 돌 비용 | 돌별 생산/초 | 회수 시간 |
|---|---|---|---|
| 외부 | 15 | 0.4 | 37초 |
| 중간 | 25 | 0.8 | 31초 |
| 안쪽 | 40 | 1.5 | **27초** |

### 3.4 자동 공격
- 사거리 `STONE_R × ATTACK_RANGE_FACTOR` (= 36px ≈ 인접)
- 공격자 1명당 `DPS_PER_ATTACKER` (= 1.5 HP/초)
- 시각: 곡선 포탄 (0.28초 발사 쿨다운)

### 3.5 변환 (오델로식)
- HP 0 도달 시 *다수 공격자 진영*으로 만렙 부활 (`FLIP_HP` = 30)
- 동수 공격이면 그냥 죽음 (애매한 경우 처리)

### 3.6 수동 다중 선택 + 집중 공격
- 내 돌 탭/드래그 라쏘 = 선택 추가/토글
- 적 탭 = 선택된 돌들이 그 적만 공격 (사거리 무관)
- 집중공격은 *동수를 깨는 핵심 도구* — 변환 보장

### 3.7 승리
- 한쪽 돌 전멸 OR `MAX_T` 후 다수 (격차)

## 5. 시뮬레이션 목표

**매크로** (개정 룰 검증):
- 타워 크기·CAP·생산률 조합 → "1일 플레이 패턴": 몇 시간마다 수확? 하루 수확량? 새 타워 몇 개 가능?
- 너무 빠르면: 늘 가득 차서 손실. 너무 느리면: 의미 없는 단순 클릭.
- **목표**: 하루 2~4회 접속 시 자연스러운 관리 게임

**마이크로** (밸런스 검증):
- 링 비용·생산·DPS 조합 → 결판 시간 / 안쪽 점거율 / 양쪽 균형
- **목표**: 60~120초 결판, 안쪽 채택 30%+, 양쪽 승률 40~60%

결과 본 문서 7장에 누적.

## 7. 시뮬레이션 결과

### 7.1 매크로 경제 (1일 시뮬, per-tower 저장·수확 룰)

핵심 발견: **cap 도달 시간 = `CAP_FACTOR / PROD_COEF` (타워 사이즈와 무관)**.
즉 큰 타워든 작은 타워든 가득 차는 시간은 같고, 크기는 *생산량 절대값*만 비례 결정.

#### PROD_COEF별 cap 도달 시간 (CAP_FACTOR=3 고정)
| PROD_COEF | 가득 차는 시간 | 평가 |
|-----------|----------------|------|
| 0.00001   | 83시간         | 너무 느림, 의미 없음 |
| 0.00003   | 27.8시간       | 1일 1회 접속해도 손실 없음 — 너무 너그러움 |
| **0.0001** | **8.3시간**   | **하루 3회 접속에 적합 ✓** |
| 0.0003    | 2.8시간        | 적극 접속 요구 (피로) |
| 0.001     | 50분           | 모바일 알람 게임 수준 |
| 0.003     | 16.7분         | 항상 켜둬야 함 |

#### CAP_FACTOR × PROD_COEF 조합 (3 시나리오 × 24시간)
시나리오:
- **신규**: 타워 3개 [20,25,30], 하루 3회 접속 (아침/점심/저녁)
- **중간**: 타워 5개 [30,50,50,70,80], 하루 2회 (아침/저녁)
- **고인물**: 타워 10개 [50~100], 하루 1회만

| variant | 시나리오 | yield/일 | 손실% | 최종E |
|---|---|---|---|---|
| **0.0001 × 3** | 신규 | 512 | **0%** | 537 |
| **0.0001 × 3** | 중간 | 1690 | 18% | 1690 |
| **0.0001 × 3** | 고인물 | 2478 | 30% | 2478 |
| 0.0003 × 3 | 신규 | 689 | 53% | 714 |
| 0.0003 × 3 | 중간 | 1720 | 65% | 1720 |
| 0.0003 × 3 | 고인물 | 2519 | 77% | 2519 |
| 0.001 × 3 | 모든 시나리오 | 73~93% 손실 | — | — |
| 0.0003 × **5** (cap↑) | 신규 | 1139 | 22% | 1164 |
| 0.0003 × **5** (cap↑) | 중간 | 2840 | 49% | 2840 |
| 0.0003 × 2 (cap↓) | 신규 | 464 | 69% | 489 |

### 권장값 (매크로)
- `PROD_COEF = 0.0001` (= 0.01%/초)
- `CAP_FACTOR = 3.0` (반지름의 3배)
- 결과: cap 8.3h → "하루 2~3회 접속" 자연 유도, 신규는 손실 0%, 고인물은 30% 손실 (라이트하게 관리 게임 압박)

> "0.00x" 사용자 해석 = **0.0001 = 0.01%/초**. 크기 100 타워 → 0.01 E/s = 36 E/h ≈ 하루에 864 E 생산 (cap 300이므로 8.3h마다 가득).

### 권장값 (마이크로)
- `DPS_PER_ATTACKER = 2.0` (현재 1.5 → 2.0 상향)

- `MAX_T = 120` 유지 (60초는 너무 짧아 결판 의미 상실)
- `RING_INNER_INCOME = 1.5` 유지 (2.0~2.5 올려도 봇이 강하게 안쪽 선호 안 함 — 추가 보상보다는 *비용* 조절이 더 효과적)
- `RING_INNER_COST = 40` 유지 (30 낮추면 안쪽 점거 약간 늘지만 균형 손상)
- `PLACE_COOLDOWN = 0.4` 유지 (영향 미미)

#### 관찰: 안쪽 채택률 낮음 (peak 1.4/판) — 개선 여지
시뮬에서 봇은 적 근처 위주로 두고 안쪽을 별로 선호하지 않음. 안쪽 점거율을 높이려면:
- 옵션 A: **안쪽 income 3.0** + **비용 35** — 적자 위험 큰 도박이지만 대박
- 옵션 B: **안쪽에 둘 때 *주변 영향력*** (예: 안쪽 돌은 사거리 1.3배) — 새 룰 추가
- 옵션 C: 봇 AI를 강하게 안쪽 선호하도록 튜닝 (PvP에선 인간이 알아서)

→ 현재는 옵션 C 방향 (봇 약점이지 게임 룰 문제 아님) — `pickPlacement`에서 강한 봇은 안쪽 가산점 부여 중. 추가 튜닝 가능.
